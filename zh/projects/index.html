项目

我做的工具，大多是为了让自己干活更快。

阅读时长: 1 分钟
  • UW–Madison 课程 API 规范： 逆向整理出的 OpenAPI 3.0 规范和参考文档，覆盖 UW–Madison 公开的选课搜索和注册接口。与学校无关。
  • wisc-enroll-query： 一个调用这些接口、帮忙挑课的 Python 工具。
  • autoDL.skills： 让 AI 助手操作 AutoDL GPU 云 API 的智能体技能，不用打开网页控制台就能启动和查看实验。
  • myplannar： 一个本地 MCP 桥，让 Windows 上的 Codex 管理 iPhone 和 iCloud 提醒事项。
  • canvas-syllabus-sync： 把 Canvas 里的课程大纲和截止日期同步出来。
