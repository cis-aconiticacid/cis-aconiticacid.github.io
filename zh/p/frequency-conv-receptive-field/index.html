在 FFT 系数上做卷积的网络与原域 Hadamard 积的等价性

2026-11 阅读时长: 25 分钟

AI 声明：本文研究的整个问题由我发现，文本思路和研究思路也来自我。AI 贡献了关于 ReLU 学到高频的部分。本文由我和 AI 一起写成，定理由 AI 推导，实验代码由 AI 编写。

1. 研究问题

2021–2026 年有一批模型先对输入做 FFT，再沿频率方向对 FFT 系数做卷积，应用涵盖 EEG、语音增强、MRI k-space、时间序列等。图像方向的代表是 FFC（Chi 等，2020）及其后继 LaMa（Suvorov 等，2022）、FasterFC（Liu 等，2023），这些工作把“频域里的任何操作都有全局感受野”作为设计依据。由卷积定理，沿频率方向的 circular convolution 精确等于在原域逐点乘一个窗（Hadamard 积）。

因此本文研究的问题是：这类网络与由原域（时域）Hadamard 积构成的网络的等价关系。

本文的研究分为三个方向：

  1. sigmoid 类激活：整个网络与原域形式等价。
  2. ReLU、softmax：等价只能近似成立，本文研究误差能否事先确定以及误差如何逐层传播。我们最初预期这几类激活的误差都可以事先确定，结果发现 ReLU 并不稳定。
  3. 实践：本文检验两种参数化从头训练后所学结果的等价性。

证明沿以下路线进行：两层 MLP（不同激活）→ residual stream + attention → 实际模型。

设帧长 \(N\)、通道数 \(C\)、核长 \(K\)：常规短卷积与神经网络里的局部循环卷积复杂度均为 \(O(K C^2 N)\)（全局循环卷积直接计算为 \(O(C^2 N^2)\)），FFT 为 \(O(C N \log N)\)，Hadamard 积为 \(O(C^2 N)\)（不做通道混合时为 \(O(CN)\)）。主要的代价来自全局循环卷积的 \(N^2\) 复杂度，FFT 反而是代价低廉的那一步。

2. 方向一：算子等价性、双域结构与计算复杂度

频域卷积网络的线性部分精确等价于原域的 Hadamard 积；非线性部分在原域对应信号与自身的反复循环卷积，是非局部运算。因此，整个网络在原域等价于“分块对角乘窗（只混通道）与全局自卷积多项式（只混时间）的交替复合”。

2.1 记号与基本设定

设原域信号 \(x \in \mathbb{C}^N\)（下标按模 \(N\) 计算），其离散傅里叶变换（DFT）与逆变换定义为：

\[X[k] = (\mathcal{F}x)[k] = \sum_{n=0}^{N-1} x[n] e^{-2\pi i k n / N}, \qquad x[n] = (\mathcal{F}^{-1}X)[n] = \frac{1}{N} \sum_{k=0}^{N-1} X[k] e^{2\pi i k n / N}\]

本文定义三种原域基本算子：

  • Hadamard 积（乘窗算子）：\((M_w u)[n] = (w \odot u)[n] = w[n] u[n]\)。
  • 循环卷积：\((u \circledast v)[n] = \sum_{m=0}^{N-1} u[m] v[(n-m) \bmod N]\)。
  • 共轭翻转算子：\((R u)[n] = \bar{u}[-n \bmod N]\)。

在此约定下，卷积定理给出双向对偶：\(\mathcal{F}(u \circledast v) = U \odot V\)，且 \(\mathcal{F}^{-1}(K \circledast X) = N (\mathcal{F}^{-1}K) \odot x\)。

2.2 交换图与自然同构

在上述约定下，卷积定理等价于下面的交换图，其中 \(w = N\mathcal F^{-1}K\)：

\[\begin{CD} \mathbb{C}^N @>{\mathcal F}>> \mathbb{C}^N \\ @V{M_w}VV @VV{K\circledast\,\cdot}V \\ \mathbb{C}^N @>>{\mathcal F}> \mathbb{C}^N \end{CD}\]

这个交换图即 \(\mathcal F\circ M_w = (K\circledast\,\cdot)\circ\mathcal F\)。图的左列在原域，右列在频域；频域卷积层的线性部分沿横向搬到原域就是乘窗。

更一般地，设 \(G\) 是有限交换群，\(\hat G\) 是它的特征标群（\(G=\mathbb{Z}/N\) 时 \(\hat G\cong\mathbb{Z}/N\)，\(\chi_k(n)=e^{2\pi i kn/N}\)）。我们定义两个从有限交换群范畴到交换 \(\mathbb{C}\)-代数范畴的协变函子：

  • \(A(G) = (\mathbb{C}^G, \circledast)\) 是群代数。群同态 \(\varphi: G\to H\) 作用为前推 \((\varphi_* u)[h] = \sum_{\varphi(g)=h} u[g]\)。
  • \(B(G) = (\mathbb{C}^{\hat G}, \odot)\) 是对偶群上的函数代数。\(\varphi\) 作用为沿对偶映射 \(\hat\varphi:\hat H\to\hat G\)，\(\psi\mapsto\psi\circ\varphi\) 的拉回 \(\hat\varphi^* U = U\circ\hat\varphi\)。

DFT \((\mathcal F_G u)(\chi) = \sum_{g\in G} u[g]\,\overline{\chi(g)}\) 是代数同构 \(A(G)\to B(G)\)（卷积定理），并且对每个群同态 \(\varphi\) 下图交换：

\[\begin{CD} A(G) @>{\mathcal F_G}>> B(G) \\ @V{\varphi_*}VV @VV{\hat\varphi^*}V \\ A(H) @>>{\mathcal F_H}> B(H) \end{CD}\]

由 \((\mathcal F_H\varphi_*u)(\psi)=\sum_{g} u[g]\,\overline{\psi(\varphi(g))}=(\mathcal F_G u)(\psi\circ\varphi)\)，\(\mathcal F: A\Rightarrow B\) 是自然同构。

取 \(\varphi\) 为商映射 \(\pi:\mathbb{Z}/N\to\mathbb{Z}/(N/s)\) 时，\(\pi_*\) 是原域的折叠（混叠求和），\(\hat\pi^*\) 是频域按步长 \(s\) 取样，\((\hat\pi^*X)[k']=X[sk']\)。这正是 2.3 节表中“stride ↔︎ 折叠”的对应。

频域逐点激活 \(\sigma\) 与任何拉回交换：\(\sigma\circ(U\circ\hat\varphi) = (\sigma\circ U)\circ\hat\varphi\)。因此 \(\sigma\) 是 \(B\) 的底集合函子到自身的自然变换；经 \(\mathcal F\) 共轭后，原域的自卷积算子 \(\mathcal P=\mathcal F^{-1}\sigma\mathcal F\) 与所有前推交换，特别是与折叠交换：

\[\begin{CD} \mathbb{C}^{\mathbb{Z}/N} @>{\mathcal P}>> \mathbb{C}^{\mathbb{Z}/N} \\ @V{\pi_*}VV @VV{\pi_*}V \\ \mathbb{C}^{\mathbb{Z}/(N/s)} @>>{\mathcal P}> \mathbb{C}^{\mathbb{Z}/(N/s)} \end{CD}\]

乘窗 \(M_w\) 依赖于具体的窗，对一般的 \(w\) 不具有这种自然性。

2.3 等价关系

设频域网络的第 \(l\) 层为\(Z_l = K_l \circledast H_{l-1}\)，\(H_l = \sigma(Z_l)\)。

命题 2.1（No-go 定理一：不存在绕开 FFT 的替代方法）

若连续映射在原域和频域同时为逐点运算，即 \(\mathcal{F}(f(x)) = g(\mathcal{F}x)\)，则 \(f\) 必为标量乘法 \(f(x) = cx\)。因此，任何非平凡的频域逐点激活 \(\sigma(Z)\) 在原域必然是非局部的，不可能化简为原域的 Hadamard 积。

命题 2.2（非线性层的自卷积表示）

  • 多项式激活：若 \(\sigma(t) = \sum_{j=0}^d a_j t^j\)，记 \(u^{\circledast j}\) 为 \(j\) 重自卷积（\(u^{\circledast 0} = \delta\) 为原点单位脉冲），则

\[\mathcal{F}^{-1}\sigma(\mathcal{F}u) = \sum_{j=0}^d a_j u^{\circledast j}\]

  • 解析激活（sigmoid / tanh）：若在有界区间 \([-B, B]\) 上用 \(d\) 次 Chebyshev 多项式逼近 \(\sigma\)，则误差随 \(d\) 呈几何级数下降，由此可以得到任意精度的自卷积多项式等价形式。
  • 实虚分离激活（如 DCCRN）：若激活形式为 \(\sigma(\mathrm{Re}\,Z) + i\,\sigma(\mathrm{Im}\,Z)\)，由于 \(\mathrm{Re}\,Z = (Z + \bar{Z})/2\) 且 \(\mathcal{F}^{-1}\bar{Z} = Rz\)，原域表示推广为 \(u\) 与 \(Ru\) 的双变量卷积多项式（同时包含自卷积 \(u \circledast u\) 与自相关 \(u \circledast Ru\)）。

2.4 算子分析

一个 \(L\) 层频域卷积网络在原域等价于两类算子的交替复合：

\[h_l = \mathcal{P}_l \big( M_{w_l} h_{l-1} \big)\]

其中 \(M_{w_l}\) 是沿时间轴分块对角的线性算子（只做通道混合，不做时间混合），\(\mathcal{P}_l\) 是非线性自卷积算子（只做时间混合，不做通道混合）。

设帧长为 \(N\)、通道数为 \(C\)、频域卷积核长为 \(K\)、多项式次数为 \(d\)，单层计算复杂度对比如下：

实现方式单层复杂度特点
频域卷积网络（\(K\) 抽头卷积 + 频域 \(\sigma\)）\(O(K C^2 N)\)基准实现；卷积开销随核长 \(K\) 线性增长。
原域线性层（Hadamard 乘窗 \(M_w\)）\(O(C^2 N)\)相比频域卷积省去 \(K\) 倍乘法，且等价核长不受 \(K\) 限制。
原域自卷积多项式（展开 \(\mathcal{P}_l\)）直接计算 \(O(d C N^2)\)用 FFT 计算为 \(O(d C N \log N)\)，比频域直接计算更贵；用于精确分析。
混合实现（原域乘窗 + FFT）\(O(C^2 N + C N \log N)\)实际最优的精确等价实现：保留线性层的 \(K\) 倍加速，同时避免多项式逼近误差与自卷积开销。

2.5 数值验证

  • 合成数据：所有线性等价、多项式自卷积、边界项、共轭翻转及 attention 等式，两边相对误差均在 \(10^{-14}\) 量级。
  • 真实模型 DCCRN（公开预训练权重，语音增强）：6 层复数卷积全部精确等于原域乘窗加修正项，最大相对差 \(3 \times 10^{-15}\)；把第 1 层连同 BatchNorm 与多项式激活完全放在原域计算时，计算结果与频域前向结果的相对差为 \(1.9 \times 10^{-15}\)。

3. 方向二：非解析激活的误差传播、爆炸机制与逼近极限

逐层误差上界可以事先推导并严格成立，但在真实模型上该上界过松，实际逼近误差过大，因此 ReLU 类激活的多项式替代在工程上不可用。

3.1 误差精确恒等式与爆炸分类

对任意输入与权重，替代网络与原网络在第 \(D\) 层的输出误差满足精确恒等式：

\[E_D = \sum_{l=1}^{D} G_l \, r_l\]

其中 \(r_l\) 是第 \(l\) 层的多项式与激活函数之差，\(G_l\) 是后续各层“平均斜率 \(\times\) 权重”连乘构成的传播算子。

命题 3.1（单层逼近与逐层递推）

  • 单层误差：对 ReLU，误差集中在 kink（0 的邻域）附近宽 \(B/d\) 的带内，相对误差受预激活的峰值与均方根之比控制（上界 \(\le 0.42 B / (\mathrm{RMS} \cdot d)\)，进入渐近段后按 \(d^{-3/2}\) 下降）；对 sigmoid/tanh，误差随 \(d\) 呈几何级数下降。
  • 逐层递推：\(e_l \le \kappa \delta_l + L \lVert W_l\rVert_2 e_{l-1}\)，其中 \(\lVert W_l\rVert_2\) 恰好等于原域窗的最大模。当压缩条件 \(c = L\lVert W\rVert_2 < 1\) 成立时，误差上界收敛到不动点，不随深度增长。

命题 3.2（误差完全分类）

输出误差有且仅有三条途径：

  1. 越界：真实网络某层预激活超出标定区间 \([-B_l, B_l]\)。
  2. 余量不足：设真实网络第 \(l\) 层 pre-activation 的最大幅值为 \(M_l = \lVert z_l\rVert_\infty\)，标定区间留出的安全余量为 \(B_l - M_l\)。当上游误差引起的偏移 \(\lVert \tilde{z}_l - z_l\rVert_\infty\)（最坏受 \(\lVert W_l\rVert_2 e_{l-1}\) 控制）超过该余量时，替代网络的 pre-activation 被推出 \([-B_l, B_l]\)，进入多项式的发散区。
  3. 正 Lyapunov 指数：真实网络 Jacobian 连乘的 Lyapunov 指数 \(\lambda > 0\)，导致传播算子 \(G_l\) 指数放大。

按此分类构造的爆炸情形均经数值验证。例如，常规 sigmoid 网络不放大误差，原因是它自带正比于窗原点的偏置项，把激活推向饱和区；我们令卷积核系数之和为零以消去该偏置后，\(\lambda\) 由负变正，sigmoid 网络同样出现误差爆炸。

误差超过 100% 有两个原因：

  1. 静息缺陷：安静的 time-frequency 单元上，pre-activation 约等于 BatchNorm 的 offset \(o_c\)，多项式在这一点上的误差是一个逐通道常数。block 2 中 77% 的位置属于这种情况，占该层缺陷能量的 83%。
  2. 模型本身放大扰动：DCCRN 各层 \(L\lVert W\rVert_2\) 为 6–48，Jacobian 范数 5328。在 block 1 之后加入 0.1% 的白噪声时，这个扰动的相对幅度到 block 6 放大 12.2 倍；作为对照，无 bias 的随机 6 层 ReLU 网络只放大约 1.2 倍。这对应命题 3.2 的第 3 条。

  • 一个尚无解释的现象：encoder 特征误差达到 123% 时，整个模型的增强效果（SI-SDR）为 11.7 dB，高于原模型的 10.7 dB。下游的 LSTM 和 decoder 对这种扰动不敏感。

因此，多项式替代限定在 sigmoid、tanh、Swish 等解析激活上。对 ReLU 类模型，本文只保留结构性结论：线性部分精确等价，非线性部分在原域是非局部运算，也不存在实用的、与输入无关的多项式形式。对 ReLU 类模型实际可用的是第 5 节的精确替代（命题 5.0）：保留频域上的 ReLU，只把频域卷积换成原域乘窗，误差为零。

3.3 逼近形式的复杂度下界（No-go 定理二）

在原域用更优的函数形式逼近频域 ReLU 时，这类逼近存在明确的复杂度边界：

  • 仅允许乘法（复合多项式）：将三次式 \(s \leftarrow s(3-s^2)/2\) 反复复合（即矩阵符号函数的 Newton–Schulz 迭代）后，按乘法总数计，误差转为指数下降（达到 1% 误差所需从单多项式的 4096 次降至 18 步复合），且复合多项式在 \(\sqrt{3}B\) 内不越界爆炸。但由 Bernstein 下界，达到 \(b\) 位精度所需的乘法深度至少为 \(b-3\)，所以这种形式无法做到与深度无关。
  • 允许除法（有理函数）：积分表示与 Zolotarev 有理逼近可将深度压至常数 3，且有理函数永不发散。但除法在原域对应反卷积，在常规硬件上仍慢于 FFT → ReLU → IFFT。

3.4 Residual stream 与 attention

  • Residual stream（推导尚未独立核对）：恒等支路使绝对误差上界的系数变为 \(1 + L\lVert W\rVert_2 \ge 1\)，最坏情况下误差随深度线性累积，同时恒等支路也稀释了相对误差的放大；pre-norm LayerNorm 保证每行误差有界，至多线性增长。
  • Attention：频率 token 上的 softmax attention 存在精确的原域形式（卷积指数 + 反卷积归一化），但上游误差穿过 attention 时只有局部 Lipschitz 常数，且该常数随特征幅度二次增长，不存在全局常数。

4. 方向三：从头训练的等价性与非线性所在的域

在两个真实任务上（ReLU 激活），从头训练的频域卷积网络与其原域等价实现取得一致的任务指标。去掉频域非线性、退化为纯原域 Hadamard 网络后，模型失去样本之间的混合能力，性能崩塌。

4.2 分析

三种网络都是 4 层、16 通道、帧长 \(N=512\)、hop 256，从头训练，Adam（学习率 \(10^{-3}\)，cosine 退火），3000 步，batch 256，3 个 random seed。

  • 降噪：数据由 LibriSpeech 语音混入 DEMAND 噪声得到，输入 SNR 为 5.04 dB；测试在 8 个未见过的说话人和留出的噪声段上进行。网络输出为 \(X + f(X)\) 形式的残差估计。
  • 预测：数据集为 ETTh1，按 12/4/4 个月划分训练、验证、测试；数据用训练集统计量标准化，模型采用 channel-independent 设置。一帧 512 点由 416 小时历史和 96 小时未来组成，未来部分的输入置零；instance normalization 使用历史段的均值和标准差；loss 和指标只在未来 96 点上计算。

  • 线性部分逐点相等：原域等价实现里的窗由同样的 5 个抽头生成，\(w[n]=\sum_{j=0}^{4}K[j]\,e^{-2\pi i (j-2)n/N}\)。用这个窗乘原域信号再做 FFT 的结果，与直接在频域做 5-tap circular convolution 的结果相比，相对差约 \(5\times10^{-16}\)。
  • 两者参数相同，所以这一组比较检验的是实现层面的等价：两种网络学的都是那 5 个抽头，只有前向计算的路径不同，因此同一个 seed 下结果几乎相同（9.94 对 9.94，10.47 对 10.46）。残余的差别来自浮点运算顺序不同，在 3000 步训练中逐渐累积。换了参数化的是 5.2 节的“每点自由的窗”，它的函数类更大（相当于任意长的频域卷积核），结果也不同（降噪 11.65 dB，预测 0.481）。本文尚未在同一函数类下直接比较核参数化与窗参数化。
  • 优化不变性的推导：记 \(w=AK\)，\(A\) 的第 \(j\) 列为 \(e^{-2\pi i(j-2)n/N}\)，满足 \(A^{H}A=NI\)。对 \(K\) 做梯度下降时，更新量为 \(\Delta K=-\eta A^{H}\nabla_w\mathcal L\)，于是 \(\Delta w=A\Delta K=-\eta AA^{H}\nabla_w\mathcal L=-N\eta\,P\nabla_w\mathcal L\)，其中 \(P=AA^{H}/N\) 是到这 \(K\) 维子空间的正交投影。所以在 SGD 下，核参数化等同于在该子空间内、学习率为 \(N\eta\) 的窗参数化，两条轨迹重合。Adam 在各坐标上分别归一化，在 \(K\) 坐标和 \(w\) 坐标下的归一化不同，因此没有这个不变性。
  • 对照组正好是 6.22 dB 的原因：它由“逐点乘窗 + 原域逐点 ReLU”构成，第 \(n\) 个输出只依赖第 \(n\) 个输入样本，样本之间没有任何混合。这样的网络最多只能给每个样本乘一个最优增益。设干净信号与噪声的功率比为 \(\mathrm{SNR}\)，最优标量增益 \(g=\mathrm{SNR}/(1+\mathrm{SNR})\) 给出的输出信噪比为 \(1+\mathrm{SNR}\)，对 5 dB 输入即 \(10\log_{10}(1+10^{0.5})=6.19\) dB，与实测 6.22 dB 相符。
  • 三个 seed 完全相同，增加参数也无效：最优逐样本增益是一个闭式解，不同初始化都收敛到它；参数量从 8,000 增加到 819,200（每点自由的窗）后，结果仍是 6.22 dB。这个网络缺少的是样本之间的混合，参数量无法弥补。
  • 预测任务上正好等于窗口均值的原因：未来 96 个位置的输入是 0，对照组在这些位置的输出只依赖这个 0，所以是一个常数；经 instance normalization 还原后，这个常数就是历史段的均值。实测 0.7077 与“输出窗口均值”这条参照线完全相同。
  • 混合完全来自频域上的非线性：频域卷积网络的 ReLU 作用在频谱系数上，按命题 2.2 在原域是自卷积，每个输出样本依赖所有输入样本。所以“FFT + 卷积”里起作用的是在频域做非线性，卷积本身只相当于乘一个窗。作为镜像对照，时域卷积网络（时间方向 5-tap 卷积 + 原域 ReLU）在频域是逐点乘窗，它的混合只来自时间方向的局部卷积，这个网络的 4 层加输出层共 5 次卷积，感受野只有 21 个样本；它的降噪结果为 7.80 dB，预测 MSE 为 0.685，介于两者之间。

5. 替代实现：以更低的代价得到频域非线性带来的增益

由方向一，频域卷积网络里起作用的是“在某个基下做非线性”，卷积本身只是乘窗。据此，本节保留原域乘窗，把包住激活函数的变换换掉或简化，比较一种精确替代和几种近似替代的代价与任务效果。

5.1 精确替代：原域乘窗 + 一对 FFT 包住 ReLU

命题 5.0（对任意频域逐点激活精确成立，包括 ReLU）

设频域卷积网络的第 \(l\) 层为 \(H_l=\sigma(K_l\circledast H_{l-1})\)，\(\sigma\) 是任意逐点激活（ReLU、PReLU、实部虚部分别作用的 ReLU、sigmoid 等），不要求解析，也不要求是多项式。记 \(h_{l-1}=\mathcal F^{-1}H_{l-1}\)，\(w_l=N\mathcal F^{-1}K_l\)。由卷积定理 \(K_l\circledast H_{l-1}=\mathcal F(w_l\odot h_{l-1})\)，所以

\[H_l=\sigma\big(\mathcal F(w_l\odot\mathcal F^{-1}H_{l-1})\big)\]

该等式对任何输入、任何权重都逐点成立。这一层的交换图为：

\[\begin{CD} H_{l-1} @>{K_l\circledast\,\cdot}>> Z_l @>{\sigma}>> H_l \\ @V{\mathcal F^{-1}}VV @AA{\mathcal F}A @. \\ h_{l-1} @>>{M_{w_l}}> w_l\odot h_{l-1} @. \end{CD}\]

  • 被替代的只有卷积，ReLU 保持不变。 激活函数原封不动地作用在频域系数上，没有用多项式去逼近它。方向二里 ReLU 的所有困难（逼近误差只按 \(B/d\) 下降、越界溢出、静息缺陷、逐层放大）在这里都不出现：误差为零，与标定数据、输入范围、网络深度无关。
  • 代价是每层多一对 FFT。 由命题 2.1，频域上非平凡的逐点激活在原域必然是非局部的，所以这对变换省不掉；而 FFT 只有 \(O(CN\log N)\)，比它替换掉的 \(K\)-tap 卷积便宜。
  • 与方向二的分工。 方向二考察整个网络完全写成原域形式的可能，对 ReLU 的结论是否定的（多项式替代不可用）。命题 5.0 考察在不改变函数的前提下把频域卷积换成原域 Hadamard 积，对 ReLU 的结论是肯定的，条件是激活仍然在频域里做。
  • 数值核对：线性部分两种写法的相对差约 \(5\times10^{-16}\)；用 ReLU 从头训练时，两种实现在同一个 seed 下的任务指标几乎相同（降噪 9.94 对 9.94 dB，预测 MSE 0.4322 对 0.4359），差别来自浮点运算顺序。
  • 真实模型上的形式：DCCRN 这类模型用 zero padding、stride，实部虚部各一套 BatchNorm。命题 5.0 仍然成立，只是 \(w_l\odot\) 要换成方向一中带修正项的原域算子（乘窗加边界项、折叠、共轭翻转），代价需要重新计算。这一形式在 DCCRN 上的线性部分已验证到 \(3\times10^{-15}\)，但本文尚未比较整网替换后的任务指标。

命题 5.1（逐层代价与更便宜的条件）

设两种实现在进入第 \(l\) 层时特征都已在频域（上一层的激活在频域完成），输入通道 \(C_{in}\)、输出通道 \(C_{out}\)。计数单位是复数乘法；一次长度 \(N\) 的 FFT 按 \(N\log_2 N\) 次计（radix-2 实际约 \(\tfrac12 N\log_2N\) 次，这样计偏保守）。

两种实现的乘法次数逐步计数如下：

  • 频域卷积网络：每个输出通道的每个频点 \(k\) 是 \(\sum_{c'}\sum_{j}K_{cc'}[j]\,H_{c'}[k-j]\)，需要 \(K\,C_{in}\) 次乘法；共 \(N\,C_{out}\) 个输出值，合计 \(K N C_{in} C_{out}\)。
  • 精确替代分三步：
    1. 对 \(C_{in}\) 个输入通道各做一次 IFFT：\(C_{in}N\log_2N\)；
    2. 原域乘窗并混合通道，每个时间点是一个 \(C_{out}\times C_{in}\) 的矩阵乘向量：\(N C_{in}C_{out}\)；
    3. 对 \(C_{out}\) 个输出通道各做一次 FFT：\(C_{out}N\log_2N\)。
实现单层乘法次数
频域卷积网络：频域 \(K\)-tap 卷积 → 频域 \(\sigma\)\(K N C_{in} C_{out}\)
精确替代：IFFT → 原域乘窗 → FFT → 频域 \(\sigma\)\(N C_{in} C_{out} + (C_{in}+C_{out}) N \log_2 N\)

两者是同一个函数。精确替代省下 \((K-1)NC_{in}C_{out}\)，多付 \((C_{in}+C_{out})N\log_2N\)，所以更便宜的充要条件是

\[(K-1)\,\frac{C_{in}C_{out}}{C_{in}+C_{out}} > \log_2 N\]

输入输出通道数相等（\(C_{in}=C_{out}=C\)）时，该条件化为 \((K-1)\,C > 2\log_2 N\)。此时加速比为

\[\frac{K N C^2}{N C^2 + 2CN\log_2 N}=\frac{K\,C}{C+2\log_2N}\]

通道数越多，加速比越接近 \(K\)：乘窗本身比 \(K\)-tap 卷积少 \(K\) 倍乘法，FFT 的开销只与 \(C\) 成正比，被 \(C^2\) 的通道混合摊薄。

  • 精确替代的代价与核长 \(K\) 无关：乘窗总是 \(NC_{in}C_{out}\)。所以核越长，精确替代省得越多；窗每点自由学习时相当于长度 \(N\) 的频域卷积核，代价仍不变。
  • 通道少、核短的层不划算（如 \(C=4\)、\(K=5\) 与 \(C=8\)、\(K=3\)），这类层应保持频域卷积。
  • depthwise 卷积（每个通道只和自己卷积，没有通道混合，如 Conformer）：频域卷积的代价为 \(KNC\)，精确替代为 \(NC + 2CN\log_2N\)，加速比为 \(K/(1+2\log_2N)\)，与通道数无关。\(N=512\)、\(K=31\) 时加速比只有 1.63 倍。

  • 由命题 2.1 与 3.3，包住激活的那一对变换去不掉；若换成原域多项式或有理函数直接计算，代价更高。因此在“函数不变”的约束下，精确替代是这一类实现里最省的。

精确替代更慢的情形。 精确替代把卷积的代价 \((K-1)NC_{in}C_{out}\) 换成一对变换的代价 \((C_{in}+C_{out})N\log_2N\)。卷积本来就便宜时，这笔交换不划算：

  • 核很短：\(K=1\)（\(1\times1\) 卷积，只混通道）时卷积本身就是 \(NC_{in}C_{out}\)，精确替代只多不少，总是更慢。\(N=512\)、输入输出通道数相等时，各核长所需的最少通道数为：

    核长 \(K\)23571131
    更便宜所需的通道数 \(C\)\(>18\)\(>9\)\(>4.5\)\(>3\)\(>1.8\)任意

  • 通道少：只有一侧是 1 个通道的层（第一层、输出层），条件化为 \((K-1)\,C/(1+C)>\log_2N\)，精确替代在 16 通道时要 \(K\ge11\) 才更便宜。常见的 3–5 抽头下，这类层应保持卷积。

  • depthwise 卷积：depthwise 卷积没有通道混合，加速比为 \(K/(1+2\log_2N)\)，精确替代在 \(N=512\) 时要 \(K>19\) 才更便宜。

  • 帧长越长，门槛越高：门槛随 \(\log_2N\) 增长。从 \(N=512\) 到 \(N=4096\)，2 抽头所需的通道数从 \(C>18\) 升到 \(C>24\)，3 抽头从 \(C>9\) 升到 \(C>12\)。

  • 二维核：DCCRN 的核是频率向 5 × 时间向 2。乘窗只替换频率方向，时间方向的 2 个抽头仍是卷积，两种实现都要付，所以加速比按频率方向的 \(K=5\) 计算，两边都乘上时间方向的 2。

  • zero padding 与 stride：此时原域算子是乘窗加边界项和折叠（方向一），多出的修正项要另外计入，本文尚未重算这部分代价。

  • 实际运行时间：以上都是乘法次数。GPU 上 3–5 抽头的短卷积有高度优化的 kernel；FFT 有固定开销，访存量也更大，batch 小时更明显。所以按乘法次数刚刚划算的层，实际运行可能更慢。

因此在实际使用中，设计者应逐层判断：只在核长、通道数都足够大的层上换成精确替代，其余层保持频域卷积。两种写法是同一个函数，混用不改变网络。

5.3 分析

  • 精确替代在两个任务上都与频域卷积网络持平，乘法次数是它的 43%。这是唯一在两个任务上都成立的替代。
  • Haar 变换与自由窗的效果随任务改变：两者在降噪上分别高 1.0 dB 和 1.45 dB，在预测上分别差 0.31 和 0.05。一个尚未推导的解释：降噪需要一个让语音稀疏的基来逐点取舍，局部的 Haar 基就够；预测需要把 416 个已知点的信息搬到 96 个未来位置，只有 FFT 这样的全局变换能做到。自由窗在预测上过拟合。
  • 时域卷积网络的感受野每层只有 5 个样本，它在预测时几乎到达不了未来区间，在降噪上也比频域网络低 2.4 dB。
  • 全局内积调制窗在预测上的失败由实验设计造成：输入里未来 96 个位置被置零，只做乘法的网络对它们的输出恒为零，所以它没有得到公平的测试。

6. 其他内容

6.1 多项式闭包与表达能力

  • 频域卷积与原域 Hadamard 积互为对偶，对线性运算精确封闭。多项式激活在两域之间也封闭：频域的 \(d\) 次逐点多项式对应原域的 \(d\) 重自卷积，项数有限。
  • ReLU、sigmoid 不封闭，它们的原域形式需要无穷多项。这一点与表达能力直接相关：激活函数非多项式是前馈网络 universal approximation 的充要条件（Leshno、Lin、Pinkus、Schocken，1993）；多项式网络的表达能力可以用代数簇的维数刻画（Kileel、Trager、Bruna，2019）。
  • 同态加密方向已有用复合 minimax 多项式替代 ReLU 的工作（arXiv:2105.10879，ResNet-152 精度 77.52% 对 78.31%），以及按每层输入分布分配多项式次数的工作（arXiv:2310.10349）。后者与本文“按分布加权拟合、逐层分配次数”的做法相近。

6.2 三种误差的区分

  • 逼近误差：这类误差由多项式代替激活函数引起，是方向二研究的对象。
  • 优化误差：这类误差由训练没有收敛到最优引起，与本文的等价关系无关。
  • 舍入误差：这类误差由浮点运算引起。高次多项式在区间外按 \(T_d(|t|/B)\) 增长，双精度下 \(d=128\) 时舍入部分比精确算术大十几个数量级，所以次数不应高于达到目标精度所需。

前向传播中误差被放大的程度就是 conditioning（Jacobian 增益 ÷ 信号增益）。反向传播用的是同一个 Jacobian 的转置，所以前向放大误差的网络，反向也放大梯度误差。

7. 开放问题：局部算子相对全局算子的位置

本文保留一个开放问题：用这种架构来解释局部算子相对全局算子放置的位置。目前的实验论文有：

  • Conformer（Gulati 等，2020）：该文只在 LibriSpeech 上做了消融。卷积放在后面最好，但只比放在前面好 0.1 WER，而且没有报告方差，所以这个差别可能只是随机波动。
  • Squeezeformer（Kim 等，2022）：该文认为大核卷积紧跟在 attention 后面是冗余的，但没有比较两种顺序。
  • Branchformer（Peng 等，2022）：该文把两者并行，并学习合并权重。它观察到浅层两支交替起作用、深层 attention 占主导，但这只是经验观察，没有解释。

Conformer 正好反过来：它在时间方向卷积，等价于沿时间轴做 FFT 之后，在那个频域里逐点乘窗。

在那个频域里看，Conformer 的卷积只是对每个频率分量乘一个系数，相当于一个滤波器，不把不同的频率分量混在一起。混合来自它后面的部分，也就是 Swish 激活和 attention。

我们的实验结论也是这个道理：在频域卷积网络里，卷积本身只是乘窗，让每个输出依赖所有输入的是“在另一个域里做的非线性”。所以讨论“卷积放前面还是后面”，本质上是在讨论乘窗（滤波）和带来混合的那一步（非线性、attention）的先后。这给了这个经验问题一个可以推导的角度。

因此这是一个 open problem。

另一个开放问题是，能否通过一些简单的复合，使模型在不做 FFT 的情况下学到 FFT 所表达的东西。

8. 局限

  • 实验网络都很小（4 层、16 通道），预测任务上都不如最小二乘线性模型，排序只说明混合方式的差别，不说明哪种网络适合做预测。
  • 每个任务只有一个数据集；训练固定 3000 步，没有 early stopping。
  • 方向二只在两个 ReLU 类网络上实测。
  • 所有代价都是乘法次数的推导，没有测运行时间。
