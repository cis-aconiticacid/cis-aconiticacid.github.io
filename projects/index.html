Projects

Tools I built, mostly to make my own work faster.

1 minute read
  • UW–Madison course API spec: a reverse-engineered OpenAPI 3.0 spec and reference docs for UW–Madison’s public course search and enrollment endpoints. Not affiliated with the university.
  • wisc-enroll-query: a Python tool that queries those endpoints to help pick courses.
  • autoDL.skills: agent skills that let an AI assistant drive the AutoDL GPU cloud API, so experiments can be launched and checked without the web console.
  • myplannar: a local MCP bridge that lets Codex on Windows manage iPhone and iCloud Reminders.
  • canvas-syllabus-sync: syncs course syllabi and deadlines out of Canvas.
